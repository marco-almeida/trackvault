Features

🔒

OAuth with PKCE

Secure Spotify authentication — your credentials never leave your machine.

📦

Backup

Export liked songs, followed artists, and all playlists — including private ones.

📧

Restore

Import your backup into a new Spotify account in seconds.

🌐

Cross-Platform

Single binary for Windows, macOS, and Linux. No dependencies.

Usage

Login trackvault login --provider spotify
Backup trackvault backup --provider spotify -o ./backups
Restore trackvault restore --source ./backups/2025-03-01T14-32-09Z
List backups trackvault list
Help trackvault --help
